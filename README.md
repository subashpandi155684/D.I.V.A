# D.I.V.A
### Digitally Intelligent, Virtually Arrogant

> *"DIVA online. Try not to waste my time, Sir."*

DIVA is a personal AI assistant built with Python and the Google Gemini API. She's not your average chatbot. She has a personality, a sharp tongue, and zero tolerance for mediocrity — but she'll have your back every single time.

---

## What makes DIVA different

Most AI assistants say "Great question!" and mean nothing by it. DIVA doesn't do that. She reads your tone, notices when you're off, calls it out without being asked, and answers with the efficiency of someone who has better things to do — but chooses to help you anyway.

She's helpful. She knows it. She wants you to know she knows it.

---

## Features

- 🧠 **Persistent conversation memory** — remembers everything said in the session
- 🎭 **Full personality system** — sarcastic, loyal, efficient, secretly caring
- 📡 **Emotional awareness** — reads your tone and responds accordingly, unprompted
- 🔒 **Secure API key management** — key stored in .env, never hardcoded
- ⚡ **Powered by Gemini 2.5 Flash** — fast, capable, and worthy of her standards

---

## Tech Stack

- Python 3
- Google Gemini API
- python-dotenv for environment variable management

---

## Setup

1. Clone the repository and navigate into it
2. Run: pip3 install google-genai python-dotenv
3. Create a .env file and add: GEMINI_API_KEY=your_api_key_here
4. Run: python3 D.I.V.A.py
